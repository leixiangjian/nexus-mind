## 一、项目介绍

### 1.1 我们是谁

**NexusMind 智慧大脑** 是一款面向企业的 **AI 智能体（Agent）编排与调度平台**。它把大语言模型、虚拟执行环境、角色化机器人、工具链（MCP / Skills）与业务流程统一到一个可视化"指挥中枢"中，让企业可以像组建团队一样，组建属于自己的 AI 工作队伍。

### 1.2 我们要解决什么

企业在落地 AI 时，普遍面临以下痛点：

| 痛点        | 现状                       | NexusMind 的答案           |
| --------- | ------------------------ | ----------------------- |
| **能力孤岛**  | 一个模型能回答，但不能干活；一个机器人只做一件事 | 让智能体之间通过工作流协作，串联成完整业务链路 |
| **黑盒执行**  | 大模型调用后，企业内部无法审计其访问了什么资源  | 虚拟系统级权限约束，网络、文件访问全部白名单  |
| **不可测**   | AI 任务上线前无法验证，结果飘忽不定      | 每个任务、每个工作流都内置"测试验证"关卡   |
| **人工调度**  | 任务谁来做？机器人怎么分配？全靠人工指派     | 智能分配引擎按角色自动匹配空闲机器人      |
| **过程不可见** | 执行中无法暂停、无法查看进度、无法追溯      | 监控中心实时显示每个机器人的行动轨迹      |
| **缺少闭环**  | 执行完没有报告，无法复盘优化           | 报告大厅提供进度、效率、成功率多维视图     |

### 1.3 设计理念

> **"让智能体成为可被管理的数字员工"**

- **角色化**：每个机器人有明确的岗位职责（数据分析师、采集员、审核员……）
- **权限化**：每个角色绑定一个虚拟系统，其能访问的网络和文件被严格约束
- **流程化**：任务不能孤军奋战，必须编排进工作流
- **可测化**：未通过测试的工作不能激活，未激活的工作不能被调度
- **可观测**：全链路日志、轨迹、报告，一切可追溯

## 二、核心概念

理解 NexusMind，先理解 6 个关键词：
模型 (Model) 虚拟系统 (VM)
│ │
└────────┬─────────────────┘
▼
角色 (Role) ←── 能力 + 权限
│
▼
机器人 (Robot) ←── 角色的可执行实例
│
▼
任务 (Task) ←── 提示词 + MCP + Skills + 测试用例
│
▼
工作 (Work) ←── 由任务节点组成的有向图
│
▼
智能分配 → 执行 → 监控 → 报告

| 概念       | 说明                                               | 类比        |
| -------- | ------------------------------------------------ | --------- |
| **模型**   | 大语言模型接入配置（OpenAI / Anthropic / DeepSeek / 通义千问等） | 员工的"大脑"   |
| **虚拟系统** | 隔离沙箱，定义网络访问与文件系统权限                               | 员工的"办公环境" |
| **角色**   | 岗位职责 + 绑定虚拟系统 + 绑定能力                             | 岗位说明书     |
| **机器人**  | 角色的一个具体执行实例，可空闲/忙碌                               | 员工本人      |
| **任务**   | 最小业务单元，含 Prompt、MCP 工具、Skills、测试用例               | 一项工作动作    |
| **工作**   | 由多个任务节点与依赖边组成的有向无环图                              | 一条业务流水线   |

## 三、业务功能

### 3.1 主屏 · 智慧大脑

启动即见的全息主屏，中央是动态马赛克脸谱（思考时波动加剧），周围环绕六大能力卡片，点击任意卡片进入对应模块。左上角是品牌标识，右上角实时显示"大模型 / 虚拟系统 / 机器人 / 运行中"的全局统计。右下角悬浮一个"智慧大脑"面板，可拖动、可折叠，作为全局引导。

### 3.2 智慧配置中心

**四个标签页，配置一切可配置项：**

- **智能体大模型** —— 管理多家 LLM 提供商。支持配置 API Key、Base URL、Temperature、Max Tokens、上下文长度，一键"启用/禁用"。
- **虚拟系统** —— 为每个角色提供独立沙箱。可精细设置：
  - **网络访问白名单**：主机 + 端口 + 允许/禁止
  - **文件系统权限**：目录路径 + `rw` / `ro` / `none`
- **机器人角色** —— 定义岗位。每个角色包含图标、颜色、能力标签、描述、绑定虚拟系统。
- **工作机器人** —— 角色的实例。显示空闲/忙碌状态、累计任务数、成功率。

### 3.3 工作任务

创建 Agent 任务。这是 NexusMind 的最小业务单元，配置项非常丰富：

- **基础信息** —— 名称、Agent 类型（trigger / analyze / crawl / fileproc / compute / render / report / human / end）、绑定角色
- **Prompt** —— 任务指令
- **模型绑定** —— 选用哪个 LLM
- **运行时参数** —— 超时秒数、重试次数、输出格式
- **MCP 工具引入** —— 添加 MCP 服务器（名称 + 地址），可启用/禁用
- **Skills 技能引入** —— 添加技能（名称 + 描述）
- **角色可操作虚拟系统目录** —— 自动展示该角色绑定 VM 的文件与网络权限，一目了然
- **测试用例** —— 每条用例含名称、输入描述、期望输出

**测试验证** 是硬门槛：点击后执行完整的"构建 → 挂载 → 加载 MCP → 加载 Skills → 逐条执行测试用例"流程，右侧控制台实时输出彩色日志。测试失败的任务无法用于工作编排。

### 3.4 工作（工作流编排）

以可视化画布的方式，将任务组装成工作流。

- **左侧节点工具栏** —— 核心节点（开始/结束/条件分支/并行分支/等待/通知/人工审批）+ 任务节点（来自"工作任务"模块）
- **画布** —— 2000×1000 可缩放、可平移，支持网格、吸附、自动布局、适应窗口
- **节点** —— 拖拽移动，区分"自动节点"与"机器人节点"
- **连线** —— 定义任务间的依赖关系
- **属性抽屉** —— 点击节点或连线，右侧弹出属性面板，可编辑坐标、查看绑定信息、删除节点/连线
- **测试验证** —— 弹出测试进度窗口，节点逐个高亮，实时日志输出，通过后可激活
- **删除工作** —— 仅未激活 / 草稿状态可删除，已激活 / 运行中 / 已完成的工作受保护

### 3.5 智能分配执行

工作激活后，进入智能分配环节。

- **选择工作** —— 下拉选择要分配的工作
- **开始智能分配** —— 系统按顺序扫描每个"机器人节点"，根据任务绑定的角色，在空闲机器人池中查找匹配：
  - 优先匹配同角色的空闲机器人
  - 无同角色时回退到任意空闲机器人
  - 无可用机器人时标记为"待分配"
- **流程图实时反馈** —— 已分配（绿框 + 机器人头像）、待分配（黄虚线闪烁）、自动调度（青色标签）
- **四维统计** —— 总任务 / 已分配 / 自动调度 / 待分配
- **空闲机器人池** —— 实时展示可用机器人
- **分配完成后** —— 自动流转到监控中心并启动执行

### 3.6 监控中心

执行过程的实时驾驶舱。

- **工作选择 + 启动/暂停/继续/强制停止**
- **流程图** —— 节点位置按比例映射，连线从右边缘中点到左边缘中点，连接线不再错乱
- **机器人 Token** —— 机器人的头像会沿着执行顺序"飞"到对应节点上
- **进度面板** —— 百分比、进度条、已完成 / 总节点 / 耗时
- **机器人工作轨迹** —— 实时显示每个机器人当前状态
- **实时日志** —— 每条事件按时间戳 + 级别输出
- **自适应 + 缩放 + 拖拽平移**

### 3.7 报告大厅

- **顶部筛选** —— 按状态（全部/运行中/已完成/未激活）、按时间（全部/今日/本周）
- **统计卡片** —— 运行中工作、已完成、活跃机器人、平均成功率
- **工作实时进度卡片** —— 每个工作的节点数/依赖数/已完成数/测试状态一览，点击查看节点详情
- **机器人实时工作** —— 所有机器人状态一览
- **执行流水** —— 每次执行完成后自动记录，含节点数、耗时、状态
- **一键导出** —— 生成 JSON 报告

## 四、解决客户的具体问题

### 场景一：企业数据分析自动化的"最后一公里"

**客户痛点**：数据团队每天要做重复的"采集 → 清洗 → 计算 → 可视化 → 报告"流程，全靠人肉串联。LLM 能分析，但不会访问数据库、不会写文件、不会生成图表。

**NexusMind 方案**：

1. 在"智慧配置中心"创建 `数据分析虚拟系统`（允许访问 PostgreSQL、允许读写 `/workspace`）
2. 创建 `数据分析师` 角色并绑定该 VM
3. 在"工作任务"中创建 9 个任务：接收请求、需求分析、数据采集、数据清洗、指标计算、可视化、报告撰写、人工审核、完成交付
4. 在"工作"中编排成流水线并测试通过
5. 在"智能分配"中自动匹配机器人并启动
6. 在"监控中心"看到每个机器人依次执行
7. 在"报告大厅"导出执行报告

**结果**：原本 2 天的分析工作，缩短到 10 分钟，且每一步可追溯、可复现。

### 场景二：金融/医疗等强合规行业的 AI 落地

**客户痛点**：AI 不能随便访问外部网络、不能随意读取敏感文件，出了事必须能审计。

**NexusMind 方案**：

- 虚拟系统的**网络白名单**只放行内部 API 和指定数据库
- 虚拟系统的**文件权限**精确到目录级，`/etc` 直接 `none`
- 每个任务的 Prompt、模型、MCP、Skills、超时、重试都留存
- 执行过程完整日志，异常可回放

**结果**：满足合规审计要求，AI 使用不再"失控"。

### 场景三：多 AI 能力协同的复杂业务

**客户痛点**：一个需求需要"分析 + 采集 + 计算 + 渲染 + 撰写 + 审核"多个能力，市面上的工具只能单个调用，拼不起来。

**NexusMind 方案**：

- 工作流天然支持**串行 + 并行**（一个节点可以有多个下游）
- 支持**条件分支**、**人工审批**节点
- 每个节点可以绑定不同角色、不同模型
- 智能分配引擎自动把任务派给对应角色的机器人

**结果**：复杂业务用一张流程图表达，AI 自动协同。

### 场景四：AI 任务上线前的"沙盘演练"

**客户痛点**：AI 任务直接上生产太危险，出错成本高。

**NexusMind 方案**：

- 任务级测试：每条测试用例有明确的"输入 - 期望输出"
- 工作级测试：整条流水线跑一遍，节点逐个验证
- 只有**全部通过**的任务才能用于编排
- 只有**通过测试**的工作才能被激活
- 只有**已激活**的工作才能被智能分配执行

**结果**：生产环境永远只运行"验过货"的 AI 任务。

## 五、技术特性

- **纯前端实现** —— 单 HTML 文件，无构建、无依赖、双击即用
- **Canvas 动态渲染** —— 主屏脸谱、全息公式背景、品牌 LOGO 全部动态生成
- **SVG 流程图** —— 工作流、分配图、监控图均使用 SVG 绘制连线
- **CSS 变量主题** —— 深蓝科技风，可一键换肤
- **零框架** —— 原生 JavaScript，无 React / Vue / jQuery
- **响应式交互** —— 拖拽、缩放、平移、吸附、全屏一应俱全

## 七、项目结构

nexusmind.html          # 单文件应用（HTML + CSS + JS）
├── <style>             # 全部样式（CSS 变量 + 组件样式）

│   │   ├── mod-work    # 工作流编排
│   │   ├── mod-alloc   # 智能分配执行
│   │   ├── mod-monitor # 监控中心
│   │   └── mod-report  # 报告大厅
│   └── .floating-brain # 悬浮大脑
└── <script>            # 全部逻辑
    ├── 数据层          # MODELS / VMS / ROLES / ROBOTS / TASKS / WORKS
    ├── 渲染层          # render* 系列函数
