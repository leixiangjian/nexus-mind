1.3 架构核心决策

编号决策理由
AD-01LangGraph 作为工作流引擎，Celery 仅作调度Celery 无有向图状态管理能力，LangGraph 支持检查点、中断恢复、条件分支
AD-02PostgreSQL 同时承载业务数据 + 检查点 + 向量减少组件依赖，事务一致性由单库保证
AD-03SSE 而非 WebSocket 做实时推送执行日志是单向广播，SSE 更轻量、易穿透代理
AD-04前端渲染逻辑与后端 API 完全解耦高保真原型可复用，前端可独立部署
AD-05沙箱使用 Docker + gVisor 而非进程隔离LLM 生成的代码不可信，需要内核级隔离
AD-06MCP 工具通过 langchain-mcp-adapters 接入标准化协议，一次接入多处复用

2.4 关键组件设计

2.4.1 工作流画布（WorkflowCanvas）

基于 React Flow 12 构建，核心能力：
- 拖拽节点：从左侧工具栏拖到画布，自动创建 work_node
- 节点移动：onNodeDragStop 触发防抖更新 position
- 连线：onConnect 创建 work_edge，写入后端
- 缩放平移：内置 Zoom/Pan 控件，同步缩放比例到 Zustand
- 节点选中：点击打开右侧属性抽屉
- 撤销重做：基于操作栈记录

2.4.2 执行监控（ExecutionGraph）

基于 SVG + 绝对定位节点构建：
- 订阅 SSE /stream/executions/{id}
- 节点状态：pending → running → done/failed
- 机器人 Token：用 CSS transition 实现节点间飞行
- 进度条：doneCount / totalCount
- 暂停/停止：调用 REST API 触发后端 interrupt

2.5 SSE 订阅封装

// lib/sse/executionStream.ts
import { fetchEventSource } from '@microsoft/fetch-event-source';

export function subscribeExecution(
  executionId: string,
  onEvent: (evt: ExecutionEvent) => void,
) {
  return fetchEventSource(`/api/v1/stream/executions/${executionId}`, {
    method: 'GET',
    headers: { Authorization: `Bearer ${getToken()}` },
    onmessage(msg) {
      const event = JSON.parse(msg.data);
      onEvent(event);
    },
    onerror(err) {
      console.error('SSE error', err);
      throw err;  // 触发自动重连
    },
  });
}

3.3 应用启动流程

# src/main.py
from contextlib import asynccontextmanager
from fastapi import FastAPI
from fastapi.middleware.cors import CORSMiddleware

from src.config import settings
from src.db.session import init_db_engine
from src.core.checkpoint import init_checkpointer
from src.core.mcp_registry import MCPRegistry
from src.events.bus import event_bus
from src.api.v1.router import api_router
from src.core.observability import setup_telemetry

@asynccontextmanager
async def lifespan(app: FastAPI):
    # 1. 初始化数据库
    await init_db_engine(settings.database_url)

    # 2. 初始化 LangGraph 检查点
    checkpointer = await init_checkpointer(settings.checkpointer_conn_string)
    app.state.checkpointer = checkpointer

    # 3. 初始化 MCP 注册中心
    app.state.mcp_registry = MCPRegistry()

    # 4. 初始化事件总线
    app.state.event_bus = event_bus

    yield

    # 关闭
    await app.state.checkpointer.close()

app = FastAPI(
    title="NexusMind API",
    version="1.0.0",
    lifespan=lifespan,
)

app.add_middleware(
    CORSMiddleware,
    allow_origins=["http://localhost:3000"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)

app.include_router(api_router, prefix=settings.api_prefix)

if settings.otel_enabled:
    setup_telemetry(app)

项目约定

event: message

4.3 事件类型枚举

type触发时机关键字段
execution_started执行开始execution_id, work_id, total
build_phase构建阶段message, phase
node_start节点开始node_id, robot_id, robot_name
node_log节点内日志node_id, level, message
node_complete节点完成node_id, output, duration_ms
node_failed节点失败node_id, error
execution_paused暂停execution_id
execution_resumed恢复execution_id
execution_stopped强制停止execution_id
execution_complete全部完成done, total, elapsed_sec
human_approval_required等待审批node_id, prompt

6. 技术选型对比

6.1 工作流引擎选型

方案有向图检查点中断恢复流式输出结论
Celery Chain❌❌❌❌仅做异步调度
Airflow✅部分❌❌批处理场景，不适用
Prefect✅✅部分✅可作为备选
Temporal✅✅✅✅重，需额外服务
LangGraph✅✅✅✅选用：与 LangChain 生态无缝集成

6.2 实时推送选型

方案方向复杂度穿透代理结论
轮询单向低易实时性差
WebSocket双向高较难不需要双向
SSE单向低易选用
gRPC Stream双向高难浏览器支持差

8. 安全架构设计

8.1 安全层次

层级威胁措施
网络中间人强制 HTTPS，HSTS
认证伪造令牌JWT + 短过期 + Refresh Token
授权越权访问所有查询强制 tenant_id 过滤
数据密钥泄漏API Key AES-256 加密存储
输入注入攻击Pydantic 校验 + SQL 参数化
Prompt提示词注入敏感指令过滤 + 输出审查
沙箱容器逃逸gVisor + 只读 FS + 非 root
网络数据外泄VM 级网络白名单，默认拒绝
文件敏感文件读取路径白名单，/etc 等默认 none
审计责任不可追溯所有写操作记录 audit_logs
